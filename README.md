# ST Floor Anchor

> 楼层级聊天快照与回退面板 · SillyTavern / TauriTavern 前端扩展

每次 **重roll / 删除 / 编辑** 之前自动备份当前聊天，之后随时在面板里一键切回任意历史分支。备份以原生聊天文件保存（文件名带 `[FA]` 标记），并自动从 ST 自带的聊天列表里隐藏，不干扰你正常管理聊天。

- 语言：[English](README.en.md)
- 版本：v0.1.7（SillyTavern 1.18+，兼容 TauriTavern 移动端）
- 更新日志：[CHANGELOG.md](CHANGELOG.md)

## 功能

- **自动快照**：重roll、删除、编辑前自动备份当前聊天；内容指纹去重，API 断连时的误触不会产生垃圾备份。
- **分支树面板**：递归编号 `br_000` → `br_000-1` → `br_000-1-1`，一眼看清回退路径。
- **一键回退**：点 Switch 切到任意历史快照，回退本质就是切换聊天。
- **快照管理**：Prune 删除不需要的快照（编号自动重排），两步确认防止误删。
- **按聊天隔离**：每个聊天各自一棵独立撤销树，切换聊天或角色卡互不干扰。
- **正文预览**：每个分支显示最后一条正文（超长滚动显示），可过滤预设状态栏/思维链等标签。
- **新建角色楼层**：回复卡在 thinking 里、正文出不来导致楼层不可编辑时，直接新建一个角色消息楼层把内容放进去（自动生成 rescue 快照）。

## 安装

### SillyTavern（桌面）

1. 顶部菜单打开 **Extensions → Install extension**。
2. 粘贴仓库地址：

   ```
   https://github.com/Icey0111/st-floor-anchor
   ```

3. 安装完成后刷新页面。

也可以用链接安装 zip：

```
https://github.com/Icey0111/st-floor-anchor/archive/refs/heads/main.zip
```

### TauriTavern（移动端）

在扩展安装界面粘贴同样的仓库地址即可。移动端已做专门适配：面板居中、可拖动、半屏占位、安全区与输入法避让。

## 使用

1. 任意消息的操作按钮区（铅笔和“…”之间）有一个小图标，点击打开 Floor Anchor 面板。
2. 每次重roll / 删除 / 编辑前插件都会自动创建快照，面板中会出现新的分支。
3. 点 **Switch**（回退图标）切回某个历史快照；点 **Prune**（垃圾桶图标）删除快照。
4. 面板右上角的 **+** 可新建一个角色消息楼层：把卡在 thinking 里的正文粘贴进去，点 Add floor（或 Ctrl+Enter）。
5. 设置（扩展面板 → Floor Anchor 抽屉）：分支预览长度、需要从预览中过滤的 XML 标签（如预设的状态栏/思维链标签）。

## 分支编号规则

| 编号 | 含义 |
|------|------|
| `br_000` | 当前聊天的根 |
| `br_000-1` / `br_000-2` | 根下的历史快照 |
| `br_000-1-1` | 从快照 `br_000-1` 继续产生的递归分支 |

每个聊天都独立从 `br_000` 开始编号；切换聊天后，面板会自动显示当前聊天自己的树。

## FAQ

**备份存在哪里？**
作为原生聊天文件保存在对应角色的聊天目录里，文件名带 `[FA]` 标记，并自动从 ST 原生聊天列表隐藏，不会让聊天管理变得冗余。

**为什么根节点没有 Prune 按钮？**
根节点是当前正在使用的聊天本身，删除它等于删除整个对话，所以只对快照开放 Prune。

**支持群聊吗？**
暂不支持（v1 仅单人聊天），群聊中不会创建快照。

**如何卸载并清理备份？**
在 ST 扩展管理中移除插件，然后手动删除聊天目录里所有文件名带 `[FA]` 的 `.jsonl` 文件即可。

**预览显示的是思维链而不是正文？**
预览只取消息正文（`mes`），思维链永远不会作为预览；如果某些预设把正文包在自定义标签里，可在设置中添加过滤标签。
