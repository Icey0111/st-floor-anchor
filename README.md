# ST Floor Anchor

SillyTavern UI extension: floor-based chat snapshots with a panel-managed
branch tree. Roll/delete/edit snapshot the current chat first (no chat
switch), rollback = switching chats from the panel.

- Design docs: [dev_docs/00_overview.md](dev_docs/00_overview.md)
- Data layer (M1): `src/model/` - pure JS, unit-tested with `npm test`.

Status: M1 (data layer) in progress.
